# 水墨三角形主题

一个基于 Typecho 的博客主题，以水墨色三角形为主要设计元素。

## 主题特点

- 🎨 水墨色配色方案（深墨、中墨、浅墨、淡墨）
- 🔺 随机三角形装饰元素
- ✨ 点击和悬停动画效果
- 📱 响应式设计，支持移动端
- 🏷️ 完整的文章、分类、标签、归档功能
- 💬 评论系统支持

## 文件结构

```
KLins/
├── index.php          # 首页模板
├── archive.php        # 归档页模板
├── page.php           # 独立页面模板
├── post.php           # 文章详情页模板
├── header.php         # 头部模板
├── footer.php         # 底部模板
├── sidebar.php        # 侧边栏模板
├── comments.php       # 评论模板
├── functions.php      # 主题功能文件
├── style.css          # 样式文件
└── script.js          # JavaScript 动画文件
```

## 安装方法

### 方法一：手动安装

1. 将整个 `KLins` 文件夹上传到 Typecho 的 `/usr/themes/` 目录下
2. 登录 Typecho 后台
3. 进入「控制台」→「外观」
4. 找到「水墨三角形」主题并启用
5. 在主题设置中配置你的选项

### 方法二：打包安装

1. 将 `KLins` 文件夹压缩为 `.zip` 文件
2. 在 Typecho 后台进入「控制台」→「外观」
3. 点击「上传主题」
4. 选择压缩包并上传
5. 启用主题

## 主题配置

主题提供以下配置选项：

- **站点 LOGO 地址**：在网站标题前显示的 LOGO 图片 URL
- **侧边栏显示**：可选择显示/隐藏侧边栏各个模块
  - 显示最新文章
  - 显示分类
  - 显示标签
  - 显示归档
  - 显示其它杂项

## 文章自定义字段

文章编辑时可设置：

- **文章缩略图**：输入图片 URL，用于文章列表显示缩略图

## 水墨色配色方案

- 深墨色 (#2c3e50) - 主要文字和底部背景
- 中墨色 (#5a6c7d) - 链接和按钮悬停
- 浅墨色 (#8fa3b8) - 按钮和装饰元素
- 淡墨色 (#b8c5d4) - 背景和标签
- 水墨白 (#f8f9fa) - 页面背景

## 动画效果

- **随机背景三角形**：每2秒在页面随机位置生成三角形
- **点击动画**：点击页面产生三角形放大旋转效果
- **悬停效果**：链接和按钮悬停时显示三角形动画
