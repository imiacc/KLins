欢迎使用水墨三角形主题

2026-02-17 作者 主题介绍 0 条评论

这是一个基于 Typecho 的博客主题，以水墨色三角形为主要设计元素。主题采用了简约的设计风格，同时融入了丰富的动画效果。

点击页面任意位置可以看到三角形动画效果，悬停在链接上也会有相应的交互反馈。

修复的问题

  • 滚动条瞬间增长问题：点击特效和鼠标悬停特效不再导致页面滚动条瞬间增长
  • 鼠标指针点击位置问题：自定义光标热点已调整，点击点准确对齐到三角形尖端

测试方法：

  • 在页面各处点击，观察滚动条是否会瞬间出现
  • 尝试点击链接或按钮，感受点击点是否与鼠标指针的视觉位置一致
  • 在页面边缘区域点击，测试特效是否会导致滚动条出现

新功能测试

  • 黑夜模式：点击右下角的按钮切换 Auto/Light/Dark 模式，观察主题颜色的变化
  • 回到顶部：滚动页面超过300px后，右下角会出现向上箭头按钮，点击可平滑回到顶部
  • 目录交互：点击目录按钮后，目录会保持展开状态，再次点击才会关闭

黑夜模式说明：

  • Auto：跟随系统设置自动切换
  • Light：强制浅色模式
  • Dark：强制深色模式

主题在黑夜模式下保持了水墨色系的设计风格，同时优化了阅读体验，包括背景色、文字颜色和交互动画的调整。

如何安装主题

2026-02-15 作者 教程 1 条评论

安装主题非常简单，只需将主题文件夹上传到 Typecho 的 themes 目录，然后在后台启用即可。

以下是详细的安装步骤：

  1. 下载主题文件
  2. 将主题文件夹上传到 /usr/themes/ 目录
  3. 登录 Typecho 后台
  4. 进入外观设置
  5. 启用本主题
  6. 根据需要进行配置

主题支持多种配置选项，包括：

  • 三角形动画开关和密度控制
  • 文章目录开关和位置选择
  • 文章内容宽度自定义
  • 阅读时间和字数统计显示
  • 自定义CSS支持
  • 代码高亮主题选择
  • 黑夜模式设置

这些选项可以在主题设置面板中进行调整，以满足不同的使用需求。

主题配色方案说明

2026-02-14 作者 设计 0 条评论

本主题采用了水墨风格的配色方案，主要包含以下颜色：

  • 深墨色 (#2c3e50)：主要文字颜色
  • 中墨色 (#5a6c7d)：次要文字和装饰元素
  • 浅墨色 (#8fa3b8)：辅助装饰和强调元素
  • 淡墨色 (#b8c5d4)：背景装饰和边框
  • 背景色 (#f8f9fa)：页面主背景

在黑夜模式下，这些颜色会进行相应的调整，以提供更好的阅读体验：

  • 深墨色变为淡墨色，用于主要文字
  • 中墨色变为浅墨色，用于次要元素
  • 浅墨色变为中墨色，用于装饰
  • 淡墨色变为深色，用于边框
  • 背景色变为深蓝色调 (#1a1a2e)

这种配色方案既保持了水墨风格的美感，又确保了在不同光照条件下的可读性。

代码示例展示

2026-02-13 作者 示例 2 条评论

主题支持代码高亮功能，以下是代码示例：

function helloWorld() {
    console.log("Hello, World!");
    return true;
}

const result = helloWorld();
console.log(result);

代码块支持多种高亮主题，包括默认、Atom、Dark、Light、Monokai和Solarized等。

每个代码块都有复制按钮，鼠标悬停时会显示，点击即可复制代码内容。
